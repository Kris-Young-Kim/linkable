## 관리자 권한 설정

### 관리자 권한이란?

LinkAble 관리자 페이지에 접근하려면**관리자(admin)** 또는 **전문가(expert)** 권한이 필요합니다.

### 권한 설정 방법

1. **Clerk 대시보드 접근**

   - [Clerk Dashboard](https://dashboard.clerk.com)에 로그인

2. **사용자 선택**

   - 사용자 목록에서 관리자 권한을 부여할 사용자를 선택

3. **Private Metadata 설정**

   - 사용자의 상세 페이지에서 "Private metadata" 탭으로 이동
   - 다음 JSON을 입력:

   ```json
   {
     "role": "admin"
   }
   ```

   - 또는 전문가 권한:

   ```json
   {
     "role": "expert"
   }
   ```

4. **저장 및 확인**
   - "Save" 버튼 클릭
   - 해당 사용자가 로그인하면 헤더에 "관리자" 링크가 표시됩니다

### 권한 확인

- 관리자 권한이 설정된 사용자는 헤더 우측에 "관리자" 버튼이 표시됩니다
- 클릭 시 `/admin/dashboard`로 이동합니다

## 관리자 대시보드

**URL**: `/admin/dashboard`

### 접근 방법

1. 헤더의 "관리자" 버튼 클릭
2. 또는 직접 `/admin/dashboard` URL로 접근

### 주요 기능

#### 1. 전체 사용자 통계 데이터

전체 사용자의 활동 및 통계 데이터를 확인할 수 있습니다.

**표시되는 지표**

- **추천 만족도**: 클릭율(CTR), 전체 추천 수 클릭된 추천 수
- **K-IPPA 참여율**: 참여한 전체 평가 수 평가 수 기준의 추천 수
- **상담 완료율**: 완료된 전체 상담 수 완료된 상담 수
- **최근 활동**: 최근 30일간의 추천 수 K-IPPA 평가 수
- **평균 효과 점수**: 전체 사용자의 평균 효과 점수

**사용 방법:**

- 페이지 로드 시 자동으로 최신 데이터가 표시됩니다
- 데이터는 실시간으로 업데이트됩니다

#### 2. 사용자별 상세 통계 데이터

개별 사용자의 상세 활동 데이터를 확인할 수 있습니다.

**표시되는 정보:**

- **사용자 정보**: 이름, 이메일 등 표시
- **상담 데이터**: 전체 상담 수 완료된 상담 수
- **추천 데이터**: 전체 추천 수 클릭된 추천 수
- **K-IPPA 평가**: 평가 수 평가 결과 요약
- **평균 효과 점수**: 사용자의 평균 효과 점수
- **포인트 변동 내역**: 포인트 적립/사용 등 변동 내역
- **활성 상태**: 현재 활성 사용자

**필터링 옵션:**

- **전체 사용자**: 모든 사용자 표시
- **K-IPPA 평가 완료**: K-IPPA 평가를 완료한 사용자만 표시
- **활성 사용자**: 상담을 진행한 사용자만 표시

**사용 방법:**

1. 상단 필터에서 원하는 필터 선택
2. 사용자 목록에서 개별 사용자의 상세 정보 확인
3. 포인트 변동 내역(필터링)은 드롭다운으로 표시됩니다

## 제품 관리

**URL**: `/admin/products`

> ⚠️ **상세 가이드**: 제품 등록 방법이나 상세한 내용은 [제품 등록 가이드](./product-registration-guide.md)를 참고하세요

### 접근 방법

1. 관리자 대시보드에서 왼쪽 사이드바의 "제품 관리" 클릭
2. 또는 직접 `/admin/products` URL로 접근

### 주요 기능

#### 1. 신규 제품 등록

ISO 9999 코드에 해당하는 보조기기 제품을 등록할 수 있습니다.

**등록 가능한 항목:**

- **제품 이름** (필수): 제품의 이름
- **ISO 코드** (필수): ISO 9999 코드 (예: "15 09", "12 22")
- **가격** (선택): 제품 가격(원 단위)
- **구매 링크** (선택): 쇼핑몰, 이커머스 등 구매 링크
- **이미지 URL** (선택): 제품 이미지 URL
- **설명** (선택): 설명 텍스트
- **제조사** (선택): 제조사 또는 브랜드 (예: "naver", "naver")
- **이미지** (선택): 제품의 상세 이미지

**사용 방법:**

1. 페이지 상단의 "신규 제품 등록" 버튼에서 등록 폼 열기
2. 필수 항목(제품 이름, ISO 코드) 입력
3. 선택 항목 입력 (가능한 모든 정보를 입력하는 것을 권장)
4. "제품 등록" 버튼 클릭
5. 성공 메시지 확인

**주의사항:**

- 제품 이름과 ISO 코드는 필수입니다
- 가격은 숫자만 입력 가능합니다
- 구매 링크는 유효한 URL 형식이어야 합니다
- 이미지 URL은 외부 접근 가능한 URL이어야 합니다

#### 2. 제품 수정

등록된 제품의 정보를 수정할 수 있습니다.

**수정 가능한 항목:**

- 모든 등록 항목 (이름, ISO 코드, 가격 구매 링크, 이미지 URL, 설명 제조사, 이미지)
- **활성 상태**: Switch 토글로 활성/비활성 전환

**사용 방법:**

1. 수정할 제품 목록에서 "수정" 버튼 클릭
2. 수정 가능한 항목으로 전환하면 모든 항목이 수정 가능한 상태가 됩니다
3. 원하는 항목 수정
4. 활성 상태는 Switch로 토글 변경
5. "저장" 버튼 클릭하여 변경사항 저장
6. "취소" 버튼으로 수정 취소 가능

**활성 상태:**

- **활성**: 제품이 추천 목록에 표시됩니다
- **비활성**: 제품이 추천 목록에서 제외됩니다(데이터는 보존)

#### 3. 제품 삭제

등록된 제품을 삭제할 수 있습니다.

**사용 방법:**

1. 삭제할 제품 목록에서 "삭제" 버튼 클릭
2. 확인 팝업에서 "확인" 클릭
3. 제품이 데이터베이스에서 영구적으로 삭제됩니다

**주의사항:**

- 삭제된 제품은 복구할 수 없습니다
- 해당 제품과 연결된 추천 데이터는 보존되지만 제품 정보는 표시되지 않습니다

#### 4. 제품 목록 확인

등록된 모든 제품을 확인할 수 있습니다.

**표시되는 정보:**

- 제품 이름
- ISO 코드 정보
- 활성/비활성 상태 정보
- ISO 코드별 제품 개수
- 최종 업데이트 일시
- 제품 이미지
- 가격 설명 제조사
- 구매 링크 (클릭 가능)
- 이미지 다운로드 (있는 경우)

**정렬:**

- 제품 목록은 최근 업데이트 일시 순으로 정렬됩니다

## 자주 묻는 질문

### Q1. 관리자 권한을 설정했는데 접근이 안 됩니다

**A**: 다음을 확인하세요:

1. Clerk 대시보드에서 Private Metadata에 `{"role": "admin"}`이 저장되었는지 확인
2. 브라우저 캐시를 삭제한 후 로그아웃 후 다시 로그인
3. 브라우저 개발자 도구(F12)에서 콘솔 메시지 확인

### Q2. 제품을 등록했는데 추천 목록에 표시되지 않습니다

**A**: 다음을 확인하세요:

1. 제품의 `is_active` 상태가 "활성"인지 확인
2. ISO 코드가 올바르게 입력되었는지 확인
3. 제품이 해당 ISO 코드로 추천되는지 확인 (ICF 분석 결과와 ISO 매칭 확인)

### Q3. 제품 이미지가 표시되지 않습니다

**A**: 다음을 확인하세요:

1. 이미지 URL이 외부 접근 가능한지 확인 (CORS 설정)
2. 이미지 URL 형식이 올바른지 확인 (http:// 또는 https://로 시작)
3. 이미지 서버가 정상적으로 존재하는지 확인

### Q4. 사용자 데이터가 표시되지 않습니다

**A**: 다음을 확인하세요:

1. 데이터베이스에 사용자 데이터가 있는지 확인
2. 브라우저 개발자 도구에서 콘솔 메시지 확인
3. 네트워크 탭에서 API 호출이 성공했는지 확인

### Q5. 통계 데이터가 표시되지 않습니다

**A**: 다음을 확인하세요:

1. 데이터베이스의 최신 데이터를 확인
2. 통계 계산 로직 확인 (API 엔드포인트: `/api/admin/analytics`)
3. 시간은 설정 확인

### Q6. 제품을 삭제했는데 추천에서 계속 표시됩니다

**A**:

- 삭제된 제품은 데이터베이스에서 영구적으로 삭제되지만 기존에 생성된 추천(`recommendations` 테이블)은 보존되므로 이전 추천에는 표시될 수 있습니다
- 추천 데이터가 있는 제품 삭제는 신중하게 해야 합니다
- 따라서 추천 생성 이후에 삭제된 제품은 표시되지 않습니다

## 추가 정보

### API 엔드포인트

관리자 기능은 다음 API 엔드포인트를 사용합니다

- `GET /api/admin/analytics` - 전체 통계 데이터
- `GET /api/admin/users` - 사용자별 상세 통계 데이터
- `GET /api/admin/products` - 제품 목록 조회
- `POST /api/admin/products` - 신규 제품 등록
- `PATCH /api/admin/products/[id]` - 제품 수정
- `DELETE /api/admin/products/[id]` - 제품 삭제

### 로그 확인

관리자 작업은 모든 콘솔에서 로그가 기록됩니다

- 제품 생성/수정/삭제 시 로그 기록
- 사용자 데이터 조회 시 로그 기록
- 오류 발생 시 상세 로그 기록

### 보안

- 모든 관리자 API는 관리자 권한(`admin` 또는 `expert`)을 확인합니다
- 권한이 없는 사용자는 403 Forbidden 오류를 받습니다
- Private Metadata는 클라이언트에서만 접근 가능하므로 서버에서도 검증합니다
