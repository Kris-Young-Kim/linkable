## 1. 프로젝트 개요

### 1.1 제품 비전

**"장애를 능력으로 연결합니다 (Connecting Disabilities to Abilities)"**

LinkAble은 사용자의 기능적 문제를 ICF(국제기능장애분류) 기준으로 분석하고 ISO 9999 코드로 보조기기를 매칭하며, K-IPPA를 통해 효과를 검증하는**데이터 기반 보조기기 추천 플랫폼**입니다.

### 1.2 프로젝트 배경

현재 시장은 전문가 의존으로 인해 접근이 어려운 보조기기를 찾기 어렵게 만듭니다. 하지만 이제는, **16개월 경험의 보조기기 전문가와 작업치료사의 경험을 담은 AI가 탄생**, 사용자의 **작업 수행(Occupational Performance)**을 분석하여 적합한 기기를 매칭하는 '링커블' 플랫폼을 선보입니다.

### 1.3 경쟁 비교표

| 구분      | 시장 기존 플랫폼 (Naver) | 전문가 직접 상담     | LinkAble                |
| --------- | ------------------------ | -------------------- | ----------------------- |
| 접근성    | 어려움 (검색)            | 어려움 (비용 필요)   | 매우 쉬움 (AI 대화형)   |
| 전문성    | 낮음 (리뷰 기반)         | 높음 (전문가가 많음) | 높음 (전문가가 만든 AI) |
| 매칭 기준 | 검색어/카테고리만        | 경험/직감            | ICF + ISO 코드 매칭     |
| 사후 검증 | 제품/리뷰만 있음         | -                    | K-IPPA 효과 검증        |

## 2. 문제 정의

### 2.1 문제 상황 분석

#### 2.1.1 높은 발견 단계 인지 부하(Cognitive Load in Discovery)

**현상**: 현재 시장은 검색, 카테고리, 이미지로는 단순 기능의 보조기기가 존재하거나, 장애 기준의 매칭이 어려움

**사용 경험**:

- 사용자는 처음부터 신체 기능 장애(ICF-b)를 기준으로 코드별 분류(ISO Code)로 직접 매칭할 수 없음
- 예 "손 떨림(Tremor)"으로 검색하면 "Weighted Utensil(무게가 있는 식사 도구)"를 찾아야 하는 과정을 반복

**Pain Point**: 검색 실패 → 인지 부하 → 보조기기 찾기 → 사용 포기 → 신체 기능 장애의 반복

#### 2.1.2 전문가 접근 제한적 (Limited Professional Access)

**현상**: 보조기기나 작업치료사의 1:1 상담을 받으면 시간이나 비용이 필요하거나 대기 시간이 길어짐

**Pain Point**: 완료된 후 집(Home)으로 돌아가서 사용자가 '그냥 기억'으로만 제품을 설정하는 경우가 많음.

#### 2.1.3 증거 기반 효과 검증 부족(Lack of Evidence)

**현상**: 시장 제품은 '리뷰'나 '경험 지점' 기반으로만 판단

**Pain Point**: "이 제품이 정말 도움이 되는지?"라는 기능적 증거나 효과(K-IPPA) 증거가 없어, 사용자 보조기기의 지속 사용이 어려움.

### 2.2 문제 규모

- **타겟 문제**: 타겟층 약 16만명의 장애인 인구 (2025년 기준으로 20%가 증가)
- **전문 상담 시장 문제**: 약 168만명의 규모
- **보조기기 문제**: 지속적인 증가 추세

## 3. 타겟 사용자

### 3.1 Primary Target (타겟 사용자)

**타겟층**: 고령자(65+) 또는 장애를 가진 사람들의 가족(3040 보호자)

#### 페르소나 A: 원인수 노인 (72세)

- **상태**: 뇌졸중 후유증, 좌반신 마비로 인한 일상생활 사용 어려움
- **신체 기능**: 손 떨림(b765), 균형 조절(b730)
- **활동 제한**: 식사/요리 등 수행(d550), 옷 입기 버튼 누르기 어려움
- **Needs**: 전문가 없이도 음성(Voice)으로 접근하면 쉽게 찾아볼 수 있는 "추천"이 필요

#### 페르소나 B: 가족 보호자(42세 원인수 노인의 딸)

- **상태**: 직장인으로 부모님을 돌보는 직장인
- **상담 시간 부족**: 모바일로 부모님을 대신해서 찾아야 함
- **추천 부족**: "어떤 제품을 사야해서 집에 두고 싶은데"
- **Needs**: 전문가가 검증된 제품이면서 검증(Validation)과 증거 근거의 신뢰가 필요

### 3.2 Secondary Target (B2B 타겟)

**타겟층**: 병원 의료진 또는 보호기관 보조기기 전문가

**Needs**: 상담 시간을 절약하면서, 고객에게 효과적인 추천을 제공할 수 있는 CRM 시스템 필요

## 4. 수익모델 전략

### 4.1 1단계: 제휴 추천 수수료 (Affiliate Model) - MVP

**방식**: AI 추천 결과에서 '추천링크' 클릭 시 쇼핑몰/이커머스로 연결

**수익**: 추천 수수료 발생 또는 제품 구매의 3~5% 수수료(Affiliate Link) 수익

**장점**:

- 초기 비용 없음
- 초기 개발 수익 최소화

### 4.2 2단계: 데이터 수익모델 (Data Monetization) - Scale-up

**방식**: K-IPPA 검증 데이터와 제품 효과 검증 데이터를 연구기관이나 병원에 판매

**가치**: "어떤 기능 장애인에게 어떤 제품이 효과적인지?"라는 RWE(Real World Evidence) 시장

### 4.3 3단계: B2B SaaS (Subscription)

**방식**: 병원 의료진 기관에 'AI 상담 도구'를 제공하여 수익을 창출

## 6. 성공 지표

### 6.1 타겟 성과 지표(KPIs)

1. **Consultation Completion Rate**: AI 상담 완료율

   - 목표: 60% 이상

2. **Recommendation Click-through Rate (CTR)**: 추천 제품 클릭율

   - 목표: 15% 이상

3. **K-IPPA Feedback Rate**: 추천 후 검증 참여율
   - 목표: 10% 이상 (사용자 적극 활용)

### 6.2 사용자 만족 지표

- 평균 상담 시간
- 추천 만족도(클릭율 기준)
- 사용자 신뢰도(K-IPPA 참여)

### 6.3 수익모델 지표

- 월간 활성 사용자수(MAU)
- 수수료율(상담 후 추천)
- 평균 주문 가치 (AOV)

- 소셜 미디어 확산: 인스타그램의 뇌졸중 환자, 전문가 커뮤니티 보조기기 전문가의 소셜 미디어 확산으로 "대화로 보조기기 찾아서 사용합니다" 해시태그로 확산

## 10. 주의 사항 및 법적 고지

### 10.1 Non-Medical 고지

본 서비스는 의료법상 의료기관 또는 의료인 고지의 법적 고지가 아닙니다.

- '링커블'의 서비스가 의료법상 진단(Diagnosis)이나 처방(Prescription)을 제공하는 것이 아닙니다
- 본 서비스는 사용자의 **기능적 제한(Functional Limitation)**을 분석하여 보조기기를 추천하는 비의료 서비스입니다
- 모든 추천 결과는 참고용이며 의료법상 의료인의 전문적 판단과 의료인의 상담이 필요합니다

### 10.2 데이터 보호 정책

- 상담 데이터는 사용자의 동의 없이 공개되지 않는 원칙 데이터로 사용
- DB의 chat_messages 테이블에 저장 기간(약 3개월 후 자동 삭제) 정책 적용
