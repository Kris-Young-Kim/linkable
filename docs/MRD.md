Advanced MRD (Market Requirements Document)
프로젝트명: LinkAble (링커블)
작성자: 16개월 경험 보조기기 전문가 / 이시영 디자인 팀
버전: v2.0 (Activity Analysis Based)

1. 시장 문제 정의 (Market Problem) : 활동 분석 기반
   핵심 시장의 문제를 요약하면 '발견의 어려움, 사용자의 작업 수행(Occupational Performance) 개선을 위한 분석이 없습니다'
   1.1 발견 과정의 인지 부하(Cognitive Load in Discovery)
   현상: 현재 쇼핑몰 네이버, 이커머스는 수많은 종류의 보조기기가 존재하거나, 검색 코드가 없습니다
   활동 분석:
   사용자는 직접 자신의 기능 장애(ICF-b)를 문제로 인식하여 제품명(ISO Code)으로 검색할 수 없습니다.
   예 "손이 떨린다(Tremor)"라는 문제로 "Weighted Utensil(손떨림을 줄이는 식기세트)"를 찾아보는 과정을 상상해보세요.
   Pain Point: 검색 실패 -> 의사결정 어려움 구매 -> 사용 어려움 -> 기능 개선의 악순환
   1.2 전문가 접근 제한적 (Limited Professional Access)
   현상: 작업치료사나 작업치료전문가의 1:1 상담을 받으려면 시간이나 비용이 필요하거나 접근이 어렵습니다
   Pain Point: 경제적 여건이나 거리상 집(Home)으로 이동하기 어려운 사용자가 '어떤 제품을 사야하는지' 상담 받기 어렵습니다.
   1.3 데이터 기반 증거 부족(Lack of Evidence)
   현상: 제품 리뷰는 '좋다'나 '나쁘다' 수준으로만 존재
   Pain Point: "이 제품이 정말 효과가 있을까?"라는 의문에 대한 기능 개선도(K-IPPA) 데이터 기반 검증이 없어, 구매자들의 신뢰가 부족합니다.
2. 타겟 시장 및 페르소나 (Target Market & Personas)
   활동 분석 기반으로, **'제품 사용자인 '기능 장애 개선?'**이라는 핵심 가치를 타겟합니다.
   2.1 Primary Target (주요 타겟)
   타겟층: 노인층(65+) 또는 장애인 가족 보호자(3040 직장인).
   시장 규모: 고령화 사회로 인한 장애인 시장(2025년 타겟층이 20%가 증가), 장애인 시장 규모 약 168조원 규모.
   페르소나 A (원인수 노인 72세):
   상태: 뇌졸중 후유증, 좌반신 마비로 인한 일상생활 사용 어려움
   Needs: 전문가 없이도 음성(Voice)으로 접근하면 쉽게 찾아볼 수 있는 "추천"이 필요.
   페르소나 B (가족 보호자 42세):
   상태: 직장인으로 부모님을 돌보는 직장인.
   Needs: 전문가가 검증된 제품이면서 검증(Validation)과 증거 근거의 신뢰가 필요 (시간 절약).
   2.2 Secondary Target (B2B 타겟)
   타겟층: 병원 의료진 또는 보호기관 보조기기 전문가.
   Needs: 상담 시간을 절약하면서, 고객에게 효과적인 추천을 제공할 수 있는 CRM 시스템 필요.
3. 차별화 가치 제안 (Unique Value Proposition)
   "LinkAble은 무엇이 다른가?"
   기존 시장 플랫폼 (naver) 전문가 직접 상담 (Assistive Tech Center) LinkAble (MVP)
   접근성 어려움 (검색) 어려움 (비용 필요) 매우 쉬움 (AI 대화형)
   전문성 낮음 (리뷰 기반) 높음 (전문가가 많음) 높음 (전문가가 만든 AI)
   매칭 기준 검색어/카테고리만 경험/직감 ICF + ISO 코드 매칭
   사후 검증 제품/리뷰만 있음 - K-IPPA 효과 검증
   추천 제품의 정확도 향상 및 사용자 맞춤형 ICF + ISO 기반 매칭
   사후 관리 시스템/피드백 수집을 통한 K-IPPA 평가 기반 효과 검증
4. 수익모델 전략 및 수익 창출 방법 (Business Model)
   MVP 단계에서부터**'제휴 추천 수수료'와 '데이터 기반 수익화'**의 단계적 접근으로, 단기적으로 현금 흐름(Cash Flow)을 확보합니다.
   4.1 1단계: 제휴 추천 수수료 (Affiliate Model) - MVP
   방식: AI 추천 결과에서 '구매하러 가기' 클릭 시 쇼핑몰/이커머스로 연결.
   수익: 구매 전환 발생 또는 제품 구매의 3~5% 수수료(Affiliate Link) 수익.
   장점: 초기 비용 없음, 초기 개발 수익 최소화
   4.2 2단계: 데이터 수익모델 (Data Monetization) - Scale-up
   방식: K-IPPA 평가 데이터와 제품 효과 검증 데이터를 연구기관이나 병원에 판매.
   가치: "어떤 기능 장애인에게 어떤 제품이 효과적인지?"라는 RWE(Real World Evidence) 시장.
   4.3 3단계: B2B SaaS (Subscription)
   방식: 병원 의료진 기관에 'AI 상담 도구'를 제공하여 수익을 창출.
5. 시장 진입 전략 (Go-to-Market Strategy)
   5.1 초기 런칭 (Seed Phase)
   마케팅 전략: 활동 분석 기반으로 노인층 타겟, 뇌졸중 후유증 보조기기 전문가를 "무료로 보조기기 추천해드립니다" 슬로건으로
   전문가 네트워크: 16개월 경험 전문가와 이시영 디자인 팀의 전문가들이 직접 참여하여 구체적인 가이드.
   5.2 성장 (Growth Phase)
   SEO 전략으로 "손떨림 방지 식기세트 추천", "뇌졸중 후유증 보조기기" 등으로 검색하면 LinkAble의 AI 상담 페이지가 노출되도록 설정 (Next.js SSR 사용).
6. 목표 달성 지표(KPIs)
   Consultation Completion Rate: AI 상담 완료율(목표: 60% 이상).
   Recommendation Click-through Rate (CTR): 추천 제품 클릭율(목표: 15% 이상).
   K-IPPA Feedback Rate: 구매 후 평가 참여율(목표: 10% 이상 - 사용자 친화적 활용).
   추가 전문가 참여율(For Developers)
   참고 문서: 사용자 친화적이거나 전문가가 **"문제가 해결되는 보조기기 플랫폼을 만들고 싶다면 '프로젝트'의 수익을 참고하세요"**라는 문구로 참여를 유도합니다
