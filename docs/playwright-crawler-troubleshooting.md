# Playwright 크롤러 문제 해결 가이드

## 일반적인 문제

### 1. 제품 상세 정보 추출이 너무 오래 걸림

**증상**: 제품 링크는 찾았지만 상세 정보 추출 중 멈춤

**해결 방법**:
- 타임아웃을 줄여서 빠르게 실패하도록 설정
- `--max` 옵션으로 개수를 줄여서 테스트
- `--headed` 옵션으로 브라우저를 보면서 디버깅

```bash
# 더 적은 개수로 테스트
pnpm crawl:playwright --site ablelife --category "워커" --max 1

# 브라우저를 보면서 실행
pnpm crawl:playwright --site ablelife --category "워커" --max 1 --headed
```

### 2. 제품 링크를 찾을 수 없음

**증상**: "⚠️ 제품 링크를 찾을 수 없습니다."

**원인**:
- 페이지 구조가 변경됨
- JavaScript로 동적 로딩되는 경우
- 셀렉터가 맞지 않음

**해결 방법**:
- `--headed` 옵션으로 페이지 구조 확인
- 사이트 설정의 셀렉터 확인 및 수정
- `site-config.ts`에서 해당 사이트의 셀렉터 업데이트

### 3. 타임아웃 오류

**증상**: "TimeoutError" 발생

**해결 방법**:
- 네트워크 연결 확인
- 사이트 접근 가능 여부 확인
- 타임아웃 시간 증가 (코드 수정 필요)

## 성능 최적화

### 빠른 테스트를 위한 팁

1. **작은 개수로 시작**: `--max 1` 또는 `--max 2`로 시작
2. **헤드리스 모드**: 기본적으로 헤드리스 모드 사용 (더 빠름)
3. **타임아웃 조정**: 코드에서 타임아웃을 줄여서 빠르게 실패

### 제품 상세 정보 추출 최적화

현재 코드는 다음 순서로 정보를 추출합니다:
1. 제품명 (필수)
2. 모델명 (선택)
3. 가격
4. 이미지
5. 특징
6. 설명
7. 제조사

필수 정보만 추출하도록 수정하면 더 빠를 수 있습니다.

## 디버깅 팁

### 1. 브라우저를 보면서 실행

```bash
pnpm crawl:playwright --site ablelife --category "워커" --max 1 --headed
```

### 2. 스크린샷 저장

코드에 스크린샷 저장 기능을 추가하여 페이지 상태 확인:

```typescript
await page.screenshot({ path: 'debug.png', fullPage: true });
```

### 3. 콘솔 로그 확인

각 단계에서 상세한 로그가 출력되므로 어느 단계에서 멈추는지 확인 가능합니다.

## 지원 사이트

현재 지원하는 사이트:
- **ablelife** (에이블라이프)
- **wheelopia** (휠로피아)
- **carelifemall** (케어라이프몰)
- **willbe** (윌비)

각 사이트는 `site-config.ts`에 설정이 있습니다.
