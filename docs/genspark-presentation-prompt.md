     - AI 기술 발전 (Gemini API)

### 슬라이드 3: 기획 의도

**내용**:

- 제목: "프로젝트 기획 의도"
- 1. 문제 해결 목적
  - 정보 탐색의 어려움 해결
    - 수만 개의 보조기기 중 적합한 제품 찾기 어려움
    - 신체 기능 저하(ICF-b)를 기술적 사양(ISO Code)으로 번역 불가능
  - 전문가 접근성 제한 해결
    - 복지관 방문 또는 긴 대기 시간 필요
    - 급성기 이후 재가 환자의 '골든타임' 놓침
  - 데이터 기반 검증 부재 해결
    - 판매량/별점 위주의 시장
    - 기능적 효과성 데이터 전무
- 2. 서비스 목적
  - 단순 쇼핑몰이 아닌 '디지털 코디네이터' 서비스
  - 16년 경력 보조공학사/작업치료사의 임상 노하우를 AI에 학습
  - 사용자의 작업 수행(Occupational Performance) 분석 및 최적 도구 매칭
- 3. 비전
     "장애를 능력으로 연결합니다"
     데이터 기반 보조기기 추천으로 사용자의 삶의 질 개선
- 레이아웃: 인포그래픽 스타일, 각 의도를 시각적으로 표현
- 애니메이션: 각 목적이 순차적으로 나타남
