## 목적

LinkAble 관리자 페이지에서 ISO 9999 코드에 해당하는 보조기기 제품을 등록하여 사용자에게 제공합니다. 등록된 제품은 사용자의 ICF 분석 결과에 따라 자동으로 추천됩니다.

### 제품 등록의 중요성

- 사용자에게 적합한 보조기기 추천 제공
- ISO 9999 코드에 따른 체계적인 제품 관리
- 다양한 쇼핑몰, 이커머스 등 제품 정보 통합 관리

---

## 접근 방법

### 1. 관리자 권한 확인

제품 등록을 위해서는 **관리자(admin)** 또는 **전문가(expert)** 권한이 필요합니다.

- 관리자 권한 설정 방법은 `docs/admin-guide.md` 참고

### 2. 제품 관리 페이지 접근

1. 헤더에서 "관리자" 버튼 클릭
2. 사이드바에서 "제품 관리" 클릭
3. 또는 직접 `/admin/products` URL로 접근

## 제품 등록 단계별 가이드

### Step 1: 기본 정보 입력

**필수 필드:**

1. **제품 이름**

   - 예: "손떨림방지 식기세트", "휠체어용 경사로", "LED 전등 스위치"
   - 사용자가 이해하기 쉬운 명확한 이름 사용

2. **ISO 코드**
   - ISO 9999:2022 표준 코드 입력
   - 형식: 공백 포함 (예: `15 09`, `18 30`, `12 22`)
   - 자주 사용하는 ISO 코드는 [ISO 9999 코드 참고](#iso-9999-코드-참고) 섹션 참고

### Step 2: 선택 정보 입력 (권장)

3. **가격**

   - 숫자만 입력 (원 단위)
   - 예: `25000`, `150000`
   - 소수점 없이 입력

4. **구매 링크**

   - 네이버, 이커머스 11번가 등 구매 가능한 URL
   - 예: `https://www.naver.com/vp/products/...`
   - 제휴 링크 사용 권장

5. **이미지 URL**

   - 제품 이미지의 외부 접근 가능한 URL
   - 예: `https://thumbnail.image.com/product.jpg`
   - CORS 설정이 허용된 이미지 사용

6. **제조사**

   - 제품 제조사명
   - 예: "삼성", "LG", "이노베이션"

7. **카테고리**

   - 여러 쇼핑몰별 정보
   - 예: `naver`, `naver`, `11st`, `gmarket`
   - 쉼표로 구분 입력 권장

8. **설명**
   - 제품에 대한 상세 설명
   - 사용자에게 도움이 되는 정보 포함
   - 예: "손떨림으로 인한 어려움을 해결하는 손떨림방지 식기세트입니다"

### Step 3: 등록 완료

1. 모든 정보 입력 후 "제품 등록" 버튼 클릭
2. 성공 메시지 확인
3. 제품 목록에서 등록된 제품 확인

## ISO 9999 코드 참고

### ISO 9999:2022 표준

ISO 9999:2022는 보조기기를 분류하는 국제 표준입니다.

**코드 형식:**

- **Subclass 기준**: 4자리 숫자, 공백 포함 형식
- 예: `15 09` (식기 및 조리 보조기기)
- 예: `18 30` (주거 이동 보조기기)
- 예: `12 22` (이동 보행기)

### ISO 9999:2022 일반 카테고리

**중요**: 실제 ISO 9999:2022의 **일반 카테고리**가 제공됩니다. ICF 매핑이 없어도 모든 ISO 코드를 선택할 수 있습니다.

제품 등록 시 ISO 코드 선택 드롭다운에서:

- **검색 기능**: ISO 코드, 분류명, 설명으로 검색 가능
- **가격순 정렬**: 가격순으로 정렬 가능
- **일반 카테고리**: 약 50개 이상의 ISO 코드 제공

### 주요 ISO 코드 목록

| ISO 코드 | 분류명                | 설명                                   | 관련 ICF 코드    |
| -------- | --------------------- | -------------------------------------- | ---------------- |
| `15 09`  | 식기 및 조리 보조기기 | 손떨림방지 식기세트, 휠체어용 식기세트 | b765, d550       |
| `18 30`  | 주거 이동 보조기기    | 휠체어용 경사로, 이동 보조기기         | d450, e120       |
| `12 22`  | 이동 보행기           | 일반 보행기, 휠체어용 보행기           | d450, d465       |
| `12 31`  | 손목 움직임 보조기기  | 휠체어용 손목 움직임 보조기기          | b730, d410, d420 |
| `21 06`  | 시각 보조기기         | 시각 보조기기, 시력 보조기기           | b230, d115       |
| `21 27`  | 형태/고정 보조기기    | 휠체어용 보조기기                      | b235, d115       |
| `22 30`  | 의사소통 보조기기     | AAC 커뮤니케이션, 의사소통 보조기기    | d360, e125       |

**일반 ISO 코드 목록**은 제품 등록 페이지의 ISO 코드 선택 드롭다운에서 확인할 수 있습니다.

### ISO 코드 찾기

1. **ICF 분석 결과 확인**

   - 사용자 상담에서 추출된 ICF 코드 확인
   - 예: `d550` (식사하기) → ISO `15 09`

2. **매핑 테이블 참고**

   - `core/matching/iso-mapping.ts` 파일 참고
   - ICF 코드와 ISO 코드의 매핑 관계 확인

3. **ISO 9999:2022 표준 문서 참고**
   - 공식 ISO 9999:2022 문서 참고
   - `docs/iso-9999-2022-mapping-reference.md` 참고

## 필드별 상세 설명

### 필수 필드

#### 1. 제품 이름 (`name`)

**형식:** 문자열(최대 255자)

**권장 가이드:**

- 예시 좋음: "손떨림방지 식기세트", "LED 전등 스위치", "휠체어용 경사로"
- 예시 나쁨: "제품1", "보조기기", "제품"

**주의**

- 브랜드명 포함 가능: "삼성 손떨림방지 보조기기"
- 주요 기능 포함: "휠체어용 보행기, 휠체어용 손목"

#### 2. ISO 코드 (`iso_code`)

**형식:** 문자열, 공백 포함 (예: `15 09`)

**권장 가이드:**

- 올바른 형식: `15 09`, `18 30`, `12 22`
- 잘못된 형식: `1509`, `15-09`, `15.09`

**주의사항:**

- ISO 9999:2022 표준에 맞는 코드 사용
- 공백과 숫자만 포함 (영문자나 특수문자 사용 불가)
- 잘못된 ISO 코드는 추천 시스템에서 제외될 수 있음

### 선택 필드

#### 3. 가격(`price`)

**형식:** 숫자 (원 단위)

**권장 가이드:**

- 예시: `25000`, `150000`, `5000`
- 나쁨: `25,000` (쉼표 포함 불가), `25000원` (단위 포함 불가)

**주의**

- 정확한 가격 입력 권장
- 가격이 자주 변경되는 경우 최신 가격으로 업데이트

#### 4. 구매 링크 (`purchase_link`)

**형식:** URL (http:// 또는 https://)

**권장 가이드:**

- 예시: `https://www.naver.com/vp/products/123456`
- 예시: `https://shopping.naver.com/catalog/123456`
- 나쁨: `naver.com/product` (프로토콜 누락)

**주의사항:**

- 유효한 URL 형식이어야 함
- 제휴 링크 사용 권장 (수익 창출)
- 링크가 유효하지 않으면 확인 필요

**제휴 링크 생성:**

- 네이버 파트너스: [naver Partners](https://partners.naver.com)
- 이커머스 제휴: 이커머스 제휴 파트너스 페이지 참고

#### 5. 이미지 URL (`image_url`)

**형식:** 이미지 파일 URL

**권장 가이드:**

- 예시: `https://thumbnail.image.com/product.jpg`
- 예시: `https://cdn.example.com/images/product.png`
- 나쁨: 로컬 파일 경로, 깨진 이미지

**주의사항:**

- 외부 접근 가능한 URL이어야 함
- CORS 설정이 허용된 이미지 사용
- 이미지가 실제로 존재하는지 확인
- 권장 이미지 형식: JPG, PNG, WebP

**이미지 최적화**

- CDN 사용 권장
- 이미지 최적화 (용량 최소화)
- 권장 크기: 800x600px 이상

#### 6. 제조사(`manufacturer`)

**형식:** 문자열

**권장 가이드:**

- 예시: "삼성", "LG전자", "이노베이션", "보행기댁퐫제조사"
- 브랜드명 또는 제조사명 입력

#### 7. 카테고리 (`category`)

**형식:** 문자열(쉼표 구분 권장)

**권장 가이드:**

- 예시: `naver`, `naver`, `11st`, `gmarket`, `manual`
- 여러 쇼핑몰별 정보 입력
- 쉼표로 구분 입력 권장

#### 8. 설명 (`description`)

**형식:** 문자열(길이 제한 없음)

**권장 가이드:**

- 예시 좋음:
  ```
  손떨림으로 인한 어려움을 해결하는 손떨림방지 식기세트입니다
  손떨림 감소를 위한 무게추가 식기세트로 식사하기 어려움을 최소화합니다.
  식기세트는 젓가락과 숟가락으로 구성되어 있습니다.
  ```
- 예시 나쁨: "좋은 제품입니다", "추천합니다"

**주의**

- 주요 기능 및 사용자 혜택 설명
- 사용자 친화적 설명
- 주의사항 포함 가능

## 실제 등록 예시

### 예시 1: 식기 보조기기 등록

**시나리오**: 손떨림으로 인한 어려움을 해결하는 손떨림방지 식기세트 등록

**입력 정보:**

| 필드       | 값                                                                                                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 제품 이름  | 손떨림방지 식기세트                                                                                                                                                                   |
| ISO 코드   | `15 09`                                                                                                                                                                               |
| 가격       | `25000`                                                                                                                                                                               |
| 구매 링크  | `https://www.naver.com/vp/products/1234567890`                                                                                                                                        |
| 이미지 URL | `https://thumbnail.image.com/weighted-utensils.jpg`                                                                                                                                   |
| 제조사     | 보조기기제조사                                                                                                                                                                        |
| 카테고리   | `naver`                                                                                                                                                                               |
| 설명       | 손떨림으로 인한 어려움을 해결하는 손떨림방지 식기세트입니다. 손떨림 감소를 위한 무게추가 식기세트로 식사하기 어려움을 최소화합니다. 식기세트는 젓가락과 숟가락으로 구성되어 있습니다. |

**결과:**

- 사용자가 "손이 떨려서 식사하기 어려워요"라고 상담하면
- ICF 코드 `d550` (식사하기)가 추출되고
- ISO 코드 `15 09`로 매칭되어
- 해당 제품이 추천 목록에 표시됩니다

## 제품 수정 및 삭제

### 제품 수정

1. 수정할 제품 목록에서 "수정" 버튼 클릭
2. 수정 모드로 전환하면 모든 필드 수정 가능
3. 원하는 필드 수정
4. **활성 상태 토글**: Switch로 활성/비활성 전환
   - **활성**: 추천 목록에 표시
   - **비활성**: 추천 목록에서 제외 (데이터는 보존)
5. "저장" 버튼 클릭

**수정 가능한 필드:**

- 모든 등록 필드 (이름, ISO 코드, 가격 구매 링크, 이미지 URL, 제조사, 카테고리, 설명)
- 활성 상태

### 제품 삭제

1. 삭제할 제품 목록에서 "삭제" 버튼 클릭
2. 확인 팝업에서 "확인" 클릭
3. 제품이 데이터베이스에서 영구적으로 삭제됩니다

**주의사항:**

- 삭제된 제품은 복구할 수 없습니다
- 해당 제품과 연결된 추천 데이터는 보존되지만 제품 정보는 표시되지 않습니다
- 실수로 삭제한 경우 즉시 재등록해야 합니다

## 자주 묻는 질문

### Q1. ISO 코드를 어떻게 찾나요?

**A**: 다음 방법으로 확인할 수 있습니다:

1. **ICF 코드로 찾기**

   - 사용자 상담에서 추출된 ICF 코드 확인
   - `core/matching/iso-mapping.ts` 파일에서 매핑 관계 확인

2. **표준 문서 참고**

   - ISO 9999:2022 표준 문서 참고
   - `docs/iso-9999-2022-mapping-reference.md` 참고

3. **기존 제품 참고**
   - 관리자 페이지에서 기존 제품의 ISO 코드 확인
   - 유사한 제품의 ISO 코드 참고

### Q2. 같은 ISO 코드로 여러 제품을 등록할 수 있나요?

**A**: 네, 가능합니다. 하나의 ISO 코드로 여러 제품을 등록하면 사용자에게 다양한 선택지를 제공할 수 있습니다.

**예시:**

- ISO `15 09`로 등록
  - 제품 A: 손떨림방지 식기세트 (네이버)
  - 제품 B: 휠체어용 식기세트(이커머스)
  - 제품 C: 무게추 식기세트 (11번가)

모두 등록하면 추천 시스템에서 모두 표시됩니다

### Q3. 제품을 등록했는데 추천 목록에 표시되지 않아요

**A**: 다음을 확인해보세요:

1. **활성 상태 확인**

   - 제품의 `is_active` 상태가 "활성"인지 확인
   - 비활성 상태면 추천 목록에서 제외됩니다

2. **ISO 코드 확인**

   - 등록한 ISO 코드가 사용자의 ICF 분석 결과와 매칭되는지 확인
   - 예: 사용자가 "식사하기 어려워요"라고 하면 `d550` → ISO `15 09` 매칭

3. **데이터베이스 확인**
   - 제품이 실제로 데이터베이스에 저장되었는지 확인
   - 관리자 페이지에서 제품 목록 확인

### Q4. 이미지가 표시되지 않아요

**A**: 다음을 확인해보세요:

1. **이미지 URL 확인**

   - URL 형식이 올바른지 확인 (http:// 또는 https://)
   - 이미지가 실제로 존재하는지 확인

2. **CORS 설정 확인**

   - 이미지 서버의 CORS 설정 확인
   - 외부 접근 가능한 이미지인지 확인

3. **이미지 형식 확인**
   - 지원되는 형식: JPG, PNG, WebP
   - 파일 확장자 확인

### Q5. 구매 링크를 제휴 링크로 변경하고 싶어요

**A**: 제품 수정 기능을 사용하세요

1. 해당 제품에서 "수정" 버튼 클릭
2. "구매 링크" 필드에서 새로운 제휴 링크 입력
3. "저장" 버튼 클릭

**제휴 링크 생성:**

- 네이버 파트너스: [naver Partners](https://partners.naver.com)
- 이커머스 제휴: 이커머스 제휴 파트너스 페이지 참고

### Q6. 가격이 자주 변경되는데 업데이트해야 하나요?

**A**: 제품 수정 기능을 사용하여 가격을 업데이트할 수 있습니다:

1. 해당 제품에서 "수정" 버튼 클릭
2. "가격" 필드에서 새로운 가격 입력
3. "저장" 버튼 클릭

**자동화(향후 계획):**

- 제품 가격 동기화 시스템을 통해 가격 자동 업데이트 (구매 추적)
