# LinkAble 프로젝트 발표 - Canva AI 프롬프트 초안

## 사용 방법

각 섹션별로 Canva AI에 입력하여 발표 슬라이드를 생성하세요.
각 프롬프트는 독립적으로 사용 가능하며, 필요에 따라 수정하여 사용하세요.

---

## 01. 프로젝트 개요

### 슬라이드 1: 타이틀 슬라이드

```
프로젝트명: LinkAble (링케이블)
부제: "불편함을 가능성으로 연결하다 (Connecting Disabilities to Abilities)"
ICF 기반 AI 보조기기 추천 플랫폼
현대적이고 전문적인 디자인, 파란색과 초록색 계열의 신뢰감 있는 색상 사용
```

### 슬라이드 2: 프로젝트 주제 및 선정 배경

```
프로젝트 주제:
ICF(국제기능분류) 기반 AI 상담 및 보조기기 추천 플랫폼 개발

선정 배경:
1. 사회적 문제 인식
   - 고령화 사회 진입으로 장애인 시장 규모 증가 (약 168조원)
   - 2025년 타겟층 20% 증가 예상
   - 정보 비대칭으로 인한 보조기기 선택의 어려움

2. 시장 기회
   - 기존 플랫폼의 한계 (검색 기반, 전문성 부족)
   - 전문가 접근성 제한 (시간, 비용, 거리)
   - 데이터 기반 검증 부재

3. 기술적 가능성
   - AI 기술 발전 (Gemini API)
   - 국제 표준 활용 가능 (ICF, ISO 9999)
   - 실시간 학습 시스템 구축 가능
타임라인 또는 배경 설명 형식
```

### 슬라이드 3: 기획 의도

```
프로젝트 기획 의도:

1. 문제 해결 목적
   - 정보 탐색의 어려움 해결
     * 수만 개의 보조기기 중 적합한 제품 찾기 어려움
     * 신체 기능 저하(ICF-b)를 기술적 사양(ISO Code)으로 번역 불가능
   - 전문가 접근성 제한 해결
     * 복지관 방문 또는 긴 대기 시간 필요
     * 급성기 이후 재가 환자의 '골든타임' 놓침
   - 데이터 기반 검증 부재 해결
     * 판매량/별점 위주의 시장
     * 기능적 효과성 데이터 전무

2. 서비스 목적
   - 단순 쇼핑몰이 아닌 '디지털 코디네이터' 서비스
   - 16년 경력 보조공학사/작업치료사의 임상 노하우를 AI에 학습
   - 사용자의 작업 수행(Occupational Performance) 분석 및 최적 도구 매칭

3. 비전
   "장애를 능력으로 연결합니다"
   데이터 기반 보조기기 추천으로 사용자의 삶의 질 향상
인포그래픽 스타일, 각 의도를 시각적으로 표현
```

### 슬라이드 4: 프로젝트 주제의 특화 포인트

```
LinkAble의 특화 포인트:

1. 국제 표준 기반 분석
   ✅ ICF(국제기능분류) 코드 자동 추출
   ✅ ISO 9999 국제 표준 보조기기 분류 매칭
   ✅ 표준화된 데이터 구조로 정확도 향상

2. AI 기반 전문가 수준 상담
   ✅ 16년 경력 전문가의 임상 노하우 학습
   ✅ 하이브리드 매칭 시스템 (규칙 + 시맨틱 + 지식 그래프)
   ✅ 실시간 학습을 통한 지속적 개선

3. 활동 분석(Activity Analysis) 프레임워크 적용
   ✅ 문제 호소 → 해결책 탐색 → 구매 실행 → 가치 검증
   ✅ 작업치료 이론 기반 체계적 접근
   ✅ 사용자 중심 설계

4. 데이터 기반 효과 검증
   ✅ K-IPPA 평가 도구를 통한 효과성 검증
   ✅ 사용 후 피드백 기반 학습 루프
   ✅ 실증 데이터 축적 및 분석
특화 포인트를 강조하는 카드 레이아웃
```

### 슬라이드 5: 기존 유사 서비스와 차별화

```
차별화 포인트 비교표:

|------|------------------------|------------------|----------|
| 접근성 | 어려움 (검색 필요) | 어려움 (비용/시간 필요) | 매우 쉬움 (AI 대화형) |
| 전문성 | 낮음 (리뷰 기반) | 높음 (전문가 직접) | 높음 (전문가가 만든 AI) |
| 매칭 기준 | 검색어/카테고리만 | 경험/직감 | ICF + ISO 코드 매칭 |
| 사후 검증 | 제품/리뷰만 | 없음 | K-IPPA 효과 검증 |
| 데이터 구조화 | 없음 | 없음 | ICF/ISO 코드 자동 변환 |
| 실시간 학습 | 없음 | 없음 | 피드백 기반 자동 개선 |
| 접근성 준수 | 부분적 | 부분적 | WCAG 2.1 AA 완전 준수 |

핵심 차별화:
→ 국제 표준 기반 정확한 매칭
→ AI 기반 24/7 접근 가능한 전문가 수준 상담
→ 데이터 기반 효과 검증 및 지속적 개선
표 형식, 색상으로 차별점 강조, LinkAble 강조
```
