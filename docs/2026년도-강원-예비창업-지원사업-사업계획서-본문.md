## 1. 문제인식 (Problem)

### 1-1. 창업아이템의 개발동기

| 문제 영역 | 핵심 이슈 | 구체적 현상 |
|---------|---------|-----------|
| **고령화 사회 진입과 장애인 시장의 급성장** | 시장 확대 | • 2025년 초고령사회 진입 (65세 이상 인구 20% 초과)<br>• 장애인 시장 규모 약 168조원, 지속적 증가<br>• 뇌졸중, 파킨슨병 등으로 인한 기능적 제한 고령자 증가<br>• 일상생활 어려움을 겪는 고령자 증가 |
| **정보 비대칭으로 인한 보조기기 선택의 어려움** | 매칭 체계 부재 | • 기능적 문제(손 떨림, 균형 장애)와 기술적 분류(ISO 9999 코드) 매칭 체계 부재<br>• 일반 쇼핑몰 수만 개 보조기기 존재하나 검색 실패<br>• "손이 떨린다" → "무게감 있는 식사 도구" 검색 불가<br>• 검색 실패 → 의사결정 어려움 → 구매 포기 → 기능 개선 실패 악순환 |
| **전문가 접근성의 제한** | 접근성 낮음 | • 보조공학사/작업치료사 1:1 상담: 보조기기센터 방문, 긴 대기 시간, 높은 비용 필요<br>• 급성기 이후 재가 복귀 환자 '골든타임' 보조기기 찾기 어려움<br>• 거리상 집 이동 어려운 사용자 전문가 도움 접근 제한 |
| **데이터 기반 효과 검증의 부재** | 효과성 검증 불가 | • 기존 시장: 판매량/단순 별점 위주 운영<br>• 기능적 효과성 데이터 전무<br>• 구매 후 제품 실제 효과 검증 불가<br>• 신뢰도 낮음, 지속적 사용으로 이어지지 못함 |

### 1-2. 창업아이템의 목적(필요성)

**핵심 목적: "장애를 능력으로 연결하다 (Connecting Disabilities to Abilities)"**

LinkAble은 단순한 쇼핑몰이 아닌, 17년 경력의 보조공학사/작업치료사의 임상 노하우를 AI에 학습시켜, 사용자의 작업 수행(Occupational Performance)을 분석하고 최적의 도구를 매칭하는 '디지털 코디네이터' 서비스를 구현합니다.

| 해결 방안 | 핵심 기능 | 기대 효과 |
|---------|---------|---------|
| **ICF 기반 체계적 분석을 통한 정확한 매칭** | • 국제기능분류(ICF) 기준: 신체 기능(Body Function), 활동(Activity), 환경(Environment) 구조화 분석<br>• 자연어 호소("화장실 문턱 때문에 휠체어가 못 들어가") → ICF 코드(d460: 이동, e155: 건축물) 변환<br>• ISO 9999 표준 보조기기(경사로: 18 12 10) 정확 매칭<br>• 국제 표준 기반 과학적 접근 (검색어 기반 추천과 차별화) | 검색어 기반 추천 대비 정확도 향상 |
| **AI 기반 접근성 극대화** | • 17년 경력 보조공학 전문가 임상 노하우 AI 학습<br>• 언제 어디서나 전문가 수준 상담 제공<br>• 텍스트 입력 어려운 고령자: 음성 인식(STT) 및 이미지 기반 상담 기능<br>• 누구나 쉽게 접근 가능한 디지털 코디네이터 서비스 | 전문가 접근성 극대화, 24/7 상담 가능 |
| **K-IPPA를 통한 효과성 검증 루프 완성** | • 사용 후 평가(K-IPPA)를 통한 실제 기능 개선도 측정<br>• 평가 데이터 → AI 학습 → 추천 정확도 지속 향상 선순환 구조<br>• RWE(Real World Evidence) 데이터 축적: "어떤 기능 장애인에게 어떤 제품이 효과적인가?"<br>• 사용자 신뢰도 향상 및 연구기관/병원 데이터 제공 수익 모델 확장 가능 | 지속적 개선, 데이터 기반 신뢰도 향상 |

## 2. 실현가능성 (Solution)

### 2-1. 창업아이템의 개발·사업화 전략

◦ **비즈니스 모델: 3단계 수익화 전략**
- 1단계 (MVP): 제휴 추천 수수료 모델 (3~5% Affiliate Link)
- 2단계 (Scale-up): 데이터 수익화 모델 (K-IPPA 평가 데이터 판매)
- 3단계 (Growth): B2B SaaS 모델 (병원 의료진 구독 서비스)

◦ **제품 구현 정도**
- MVP 단계 완료: AI 상담 엔진, ICF 분석 시스템, ISO 매칭 엔진 구축 완료
- 데이터베이스: 1,500개 이상 보조기기 제품 데이터 수집 및 ISO 코드 매핑 완료
- 웹 플랫폼: Next.js 15 기반 반응형 웹 애플리케이션 배포 완료

◦ **제작 소요기간 및 제작방법**
- 개발 기간: 2024년 5월 ~ 2025년 1월 (약 8개월)
- 제작 방법: 자체 개발 (외주 없이 팀 내 개발)
- 기술 스택: Next.js 15, TypeScript, Supabase, Google Gemini API, Tailwind CSS

### 2-2. 창업아이템의 시장분석 및 경쟁력 확보방안

◦ **시장 분석**
- 타겟 시장 규모: 고령자(65세 이상) 약 900만 명, 장애인 인구 약 270만 명
- 장애인 시장 규모: 약 168조원, 보조기기 시장 연평균 10% 이상 성장 예상
- 주요 타겟: 고령자(65+) 또는 장애인 가족 보호자(30-40대 직장인)

◦ **경쟁력 확보방안**
1. 국제 표준 기반의 체계적 매칭 (ICF + ISO 9999 코드 기반 매칭)
2. 전문가 수준의 AI 상담 (16년 경력 전문가 노하우 AI 학습)
3. 데이터 기반 효과 검증 (K-IPPA 평가를 통한 기능 개선도 측정)
4. 접근성 극대화 (음성 인식, 이미지 기반 상담, WCAG 2.1 AA 표준 준수)
5. 지속적 학습 및 개선 (K-IPPA 평가 데이터 → AI 학습 선순환 구조)
