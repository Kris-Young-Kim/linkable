# SEO 콘텐츠 품질 가이드

이 문서는 LinkAble의 SEO 최적화를 위한 콘텐츠 품질 요구사항과 체크리스트를 제공합니다.

## 1. 키워드 조사 (Keyword Research)

### 목표 키워드 카테고리

#### 핵심 키워드 (Core Keywords)
- **보조기기**: 보조기기, 보조공학, 복지용구, 생활보조기구
- **AI 매칭**: AI 보조기기 추천, AI 상담, 보조기기 매칭
- **표준 기반**: ICF 보조기기, ISO 9999, 국제기능분류
- **효과성 검증**: K-IPPA, 보조기기 효과성, 사용성 평가

#### 롱테일 키워드 (Long-tail Keywords)
- "손 떨림 보조기기 추천"
- "고령자 일상생활 보조도구"
- "ICF 기반 보조기기 매칭 서비스"
- "AI로 찾는 맞춤형 보조기기"
- "보조기기 사용 전후 효과 검증"

#### 검색 의도별 키워드 분류

**정보성 (Informational)**
- "보조기기란 무엇인가"
- "ICF 코드 의미"
- "보조기기 효과성 평가 방법"

**탐색성 (Navigational)**
- "LinkAble"
- "링커블"
- "보조기기 추천 사이트"

**거래성 (Transactional)**
- "보조기기 구매"
- "보조기기 추천 받기"
- "AI 상담 시작하기"

### 키워드 밀도 권장사항
- 핵심 키워드: 1-2% (자연스럽게 사용)
- 롱테일 키워드: 페이지당 1-2회
- 키워드 스터핑 피하기 (과도한 반복 금지)

## 2. 자연어 및 가독성 (Readability)

### 현재 구현 상태
✅ **구현 완료**
- 모든 페이지의 콘텐츠는 자연스러운 한국어로 작성됨
- 전문 용어는 설명과 함께 사용됨
- 문장 길이는 적절하게 유지됨 (평균 15-20단어)

### 가독성 체크리스트
- [x] 문장이 명확하고 간결함
- [x] 전문 용어는 처음 사용 시 설명 포함
- [x] 단락은 3-5문장으로 구성
- [x] 헤딩을 사용하여 콘텐츠 구조화
- [x] 불릿 포인트나 번호 목록 활용

### 개선 권장사항
- 복잡한 문장은 2-3개의 짧은 문장으로 분리
- 수동태보다 능동태 사용
- "~입니다", "~합니다" 같은 존댓말 일관성 유지

## 3. 검색 의도 일치도 (Search Intent Alignment)

### 검색 의도 분석

#### 정보성 의도 (Informational Intent)
**사용자 질문 예시:**
- "보조기기가 뭔가요?"
- "ICF 코드는 어떻게 사용하나요?"
- "K-IPPA 평가는 무엇인가요?"

**대응 콘텐츠:**
- ✅ About 페이지: 서비스 소개 및 원리 설명
- ✅ FAQ 섹션 (향후 구현)
- ✅ 블로그/가이드 콘텐츠 (향후 구현)

#### 탐색성 의도 (Navigational Intent)
**사용자 질문 예시:**
- "LinkAble 홈페이지"
- "링커블 로그인"

**대응 콘텐츠:**
- ✅ 명확한 브랜드명 사용
- ✅ 브랜드 검색 최적화

#### 거래성 의도 (Transactional Intent)
**사용자 질문 예시:**
- "보조기기 추천 받기"
- "AI 상담 시작"
- "보조기기 구매"

**대응 콘텐츠:**
- ✅ 홈페이지 CTA 버튼
- ✅ 상담 시작 플로우
- ✅ 추천 페이지

### 검색 의도 매핑

| 검색 의도 | 주요 페이지 | 키워드 예시 |
|---------|-----------|-----------|
| 정보성 | `/about`, `/` | "보조기기란", "ICF 코드" |
| 탐색성 | `/` | "LinkAble", "링커블" |
| 거래성 | `/chat`, `/recommendations` | "보조기기 추천", "AI 상담" |

## 4. 콘텐츠 독창성 및 유용성 (Originality & Usefulness)

### 독창성 요소

✅ **구현된 독창적 콘텐츠:**
1. **ICF-ISO 매칭 시스템**: 국제 표준 기반 자동 매칭
2. **K-IPPA 효과성 검증**: 사용 전후 효과성 측정
3. **16년 경력 전문가 노하우**: AI 학습 데이터
4. **실제 사용자 경험 데이터**: K-IPPA 평가 기반 후기

### 유용성 체크리스트

- [x] 사용자가 실제로 필요한 정보 제공
- [x] 단계별 가이드 제공 (How It Works 섹션)
- [x] 실제 사용 사례 공유 (Testimonials 섹션)
- [x] 명확한 CTA (Call-to-Action)
- [ ] FAQ 섹션 (향후 구현)
- [ ] 상세 가이드 문서 (향후 구현)

### 콘텐츠 업데이트 계획

**정기 업데이트 항목:**
1. **사용자 후기**: K-IPPA 평가 데이터 기반 자동 업데이트
2. **통계 정보**: 월별 사용자 통계 업데이트
3. **제품 정보**: 신규 보조기기 추가 시 업데이트

**수동 업데이트 필요 항목:**
1. **블로그/가이드 콘텐츠**: 분기별 1회 이상
2. **FAQ**: 사용자 문의 기반 업데이트
3. **서비스 소개**: 주요 기능 변경 시 업데이트

## 5. 콘텐츠 품질 체크리스트

### 페이지별 체크리스트

#### 홈페이지 (`/`)
- [x] 명확한 제목 태그 (60자 이내)
- [x] 메타 설명 포함 (30-75자)
- [x] 핵심 키워드 자연스럽게 포함
- [x] H1 태그 1개만 사용
- [x] 구조화된 헤딩 (H1 → H2 → H3)
- [x] 내부 링크 포함
- [x] 이미지 alt 텍스트 포함
- [x] CTA 버튼 명확함

#### About 페이지 (`/about`)
- [x] 회사/서비스 소개
- [x] 전문가 경험 강조
- [x] 핵심 가치 설명
- [x] 연락처 정보

#### 추천 페이지 (`/recommendations`)
- [x] 페이지별 고유 메타데이터
- [x] 동적 콘텐츠 (상담 ID 기반)
- [x] 제품 정보 구조화

### 콘텐츠 작성 가이드라인

#### DO (해야 할 것)
✅ 사용자 중심 언어 사용
✅ 구체적인 예시 제공
✅ 단계별 설명
✅ 시각적 요소 활용 (이미지, 아이콘)
✅ 명확한 CTA

#### DON'T (하지 말아야 할 것)
❌ 키워드 스터핑
❌ 중복 콘텐츠
❌ 과도한 전문 용어
❌ 모호한 설명
❌ 오래된 정보 유지

## 6. 정기적인 콘텐츠 업데이트

### 자동 업데이트
- **사용자 후기**: K-IPPA 평가 제출 시 자동 반영
- **통계 데이터**: 실시간 업데이트
- **제품 정보**: 관리자 등록 시 자동 반영

### 수동 업데이트 일정
- **분기별**: 주요 콘텐츠 리뷰 및 업데이트
- **월별**: 통계 및 성과 데이터 업데이트
- **주기적**: 사용자 피드백 기반 FAQ 업데이트

### 콘텐츠 버전 관리
- 각 페이지의 마지막 업데이트 날짜 기록 권장
- 주요 변경사항은 변경 로그에 기록

## 7. 검색 의도별 콘텐츠 전략

### 정보성 의도 대응
**현재 상태**: 부분 구현
- ✅ About 페이지에서 서비스 원리 설명
- ⚠️ FAQ 섹션 미구현 (향후 추가 필요)
- ⚠️ 가이드/블로그 콘텐츠 미구현 (향후 추가 필요)

**개선 방안**:
1. FAQ 페이지 추가 (`/faq`)
2. 보조기기 가이드 섹션 추가
3. ICF 코드 설명 페이지 추가

### 탐색성 의도 대응
**현재 상태**: ✅ 구현 완료
- 브랜드명 명확히 표시
- 브랜드 검색 최적화

### 거래성 의도 대응
**현재 상태**: ✅ 구현 완료
- 명확한 CTA 버튼
- 간편한 상담 시작 플로우
- 추천 페이지로의 자연스러운 연결
