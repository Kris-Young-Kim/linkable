## 🔍 단계별 상세 분석

### 1단계: 채팅 메시지 → ICF 코드 추출

#### 정확도 지표

- **추출 성공률**: 100% (30/30 완료 상담)
- **평균 ICF 코드 수**: 4.73개/상담
- **ICF 코드 분포**:
  - b 코드 (신체 기능): 평균 1.2개
  - d 코드 (활동): 평균 2.1개
  - e 코드 (환경): 평균 1.4개

#### 주요 발견사항

✅ **강점**:

- 모든 완료된 상담에서 ICF 코드가 성공적으로 추출됨
- ICF 코드 검증 로직(`enforceIcfConsistency`)이 작동 중
- 키워드 기반 추론 규칙이 잘 정의되어 있음

⚠️ **개선 필요**:

- `consultation_icf_codes` 테이블에 데이터가 저장되지 않음 (정규화 테이블 미사용)
- ICF 코드가 `analysis_results.icf_codes` JSONB에만 저장됨
- 정규화된 테이블 활용 시 더 정확한 분석 가능

#### 추출 메커니즘

1. **AI 기반 추출** (Gemini API)

   - 사용자 메시지를 분석하여 ICF 코드 추출
   - JSON 형식으로 구조화된 응답 반환

2. **키워드 기반 보강** (`icf-validator.ts`)

   - 50개 이상의 키워드 규칙 적용
   - 예: "시각", "눈", "시력" → b210, b215

3. **일관성 검증** (`enforceIcfConsistency`)
   - 상충하는 ICF 코드 제거
   - 필수 ICF 코드 추가

### 2단계: ICF 코드 → ISO 코드 매칭

#### 정확도 지표

- **매핑 규칙 수**: 118개 (활성화됨)
- **평균 매핑 점수**: 0.70 (base_score 기준)
- **매핑 커버리지**:
  - ICF 코드당 평균 2-3개 ISO 코드 매칭
  - Division 레벨(6자리) ISO 코드 사용

#### 매칭 메커니즘

1. **규칙 기반 매칭** (40% 가중치)

   - `icf_iso_mappings` 테이블 활용
   - base_score + coverage_ratio 계산
   - 점수 공식: `base_score + (coverage * 0.3)`

2. **시맨틱 매칭** (30% 가중치)

   - 벡터 임베딩 기반 유사도 검색
   - pgvector 활용
   - 유사도 임계값: 0.7

3. **지식 그래프** (20% 가중치)

   - ICF 코드 간 관계 추론
   - 전문가 지식 기반 매칭

4. **키워드 추론** (10% 가중치)
   - 사용자 메시지에서 직접 언급된 제품 감지

#### 주요 발견사항

✅ **강점**:

- 하이브리드 매칭 시스템으로 다각도 분석
- 사전 계산된 매핑 캐시로 성능 최적화
- 피드백 기반 점수 조정 시스템 구축

⚠️ **개선 필요**:

- 실제 사용자 피드백 데이터 부족 (2개만 존재)
- 피드백 기반 학습이 제대로 작동하지 않음
- 매핑 규칙의 정확도 검증 필요
